# AI Special MacD Joint — Digital Menu

A static, mobile-first menu website designed around the restaurant's existing red, green, black and white brand identity.

## Files
- `index.html` — page structure and menu content
- `style.css` — responsive design and motion
- `script.js` — category filters and item count
- `assets/restaurant-logo.jpg` — supplied restaurant logo

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub Pages publishes, copy the live website URL.
7. Generate the QR code from that live URL.

## Before publishing
- Confirm whether the two popcorn prices represent different sizes.
- Confirm the menu is complete and all prices are current.
- Test the WhatsApp link and the published page on a phone.
- Test the final QR code on multiple phones before printing.

The menu currently uses emoji illustrations as lightweight placeholders rather than claiming stock photos are photos of the restaurant's actual food. Replace these with client-approved food photography when available.
